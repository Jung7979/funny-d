# Funny D

캐릭터 문구 브랜드 Funny D의 반응형 정적 홈페이지입니다.

별도 빌드 과정 없이 `index.html`을 브라우저에서 열어 사용할 수 있습니다.

## 구성

- 홈 및 대표 제품
- 브랜드 소개
- 제품 카테고리 필터와 찜하기
- 브랜드 이야기
- 연락 폼

## 파일

- `index.html`: 사이트 구조와 콘텐츠
- `about.html`: 판매자 인터뷰를 반영한 내 소개 페이지
- `products.html`: `products.json` 전체를 불러오는 제품 페이지
- `products.json`: 제품명, 가격, 이미지 주소, 구매 링크 데이터
- `products.js`: 홈과 제품 페이지의 상품 카드를 자동 생성하는 스크립트
- `styles.css`: 디자인 및 반응형 스타일
- `about.css`: 내 소개 페이지 전용 스타일
- `catalog.css`: 제품 카드와 제품 페이지 전용 스타일
- `script.js`: 메뉴, 필터, 찜하기, 폼 인터랙션
- `funny-d-logo.png`: 브랜드 로고

## 상품 정보

대표 제품은 스마트웍스 쿠팡 스토어에서 판매 중인 문구류 3종으로 구성했습니다. 가격은 2026년 8월 29일 확인 기준이며 실제 판매가는 쿠팡 상품 페이지에서 확인해야 합니다.

## 검색과 AI 안내 파일

`node scripts/build-seo.mjs`로 배포용 `dist/`를 만듭니다. Vercel도 같은 명령을 자동 실행합니다. 로컬 확인은 `python3 -m http.server 8001 --directory dist`로 할 수 있습니다.

- `story/posts.json`을 기준으로 새 글의 본문·FAQ·메타데이터가 담긴 HTML을 생성합니다. 기존 편집형 글 HTML은 유지합니다.
- 홈과 이야기 목록에도 글 링크를 HTML로 미리 넣습니다. 브라우저에서는 기존 JSON 자동 갱신 기능이 동작합니다.
- 배포할 때마다 사이트맵과 `llms.txt`의 글 목록을 자동 갱신합니다. 저장소 루트의 같은 파일은 현재 상태를 보여주는 사본이며, 실제 배포 파일은 빌드 결과를 사용합니다.
- 관리자 페이지는 사이트맵에서 제외하고 `noindex,nofollow`를 유지합니다. robots.txt에서는 크롤러가 이 메타 지시문을 읽을 수 있게 접근을 차단하지 않습니다. 이는 접근 통제나 인증을 대신하지 않습니다.
- 기존 `story/post.html?id=...` 주소도 동작하며, 해당 글의 고유 HTML 주소를 canonical로 안내합니다.
- 연락하기 페이지의 예시 이메일과 SNS를 실제 브랜드의 구조화된 연락처로 등록하지 않습니다.
